# Contributing

Thanks for your interest in Unstoppable Code!

This repository publishes releases and development snapshots, so we don't accept
pull requests. Any pull request opened here is closed automatically.

## Issues are welcome

[Open an issue](https://github.com/unstoppable-si/unstoppable-code/issues/new/choose)
and pick the form that fits:

- **Bugs:** use the bug report form. Tell us what happened, what you expected,
  and which app version and platform you're on. If you built from source, say
  so and name the public commit or source tag you built. Development snapshots
  have no tag, and the desktop and mobile folders can be at different revisions.
- **Ideas:** use the idea form. Describe the problem you're trying to solve.
- **Please skip code and patches.** We can't accept code contributions, so we
  build every fix ourselves. A clear description helps us most.

For questions about using the app, see the
[help centre](https://unstoppable.ai/support) or
[contact support](https://unstoppable.ai/support/troubleshooting/contact-support).

## Security issues

Please don't open a public issue. See [SECURITY.md](SECURITY.md) for how to
report a vulnerability privately.
