# Contributing

Thanks for your interest in Unstoppable Code!

This repository mirrors each release, so we don't accept pull requests. Any pull
request opened here is closed automatically.

## Issues are welcome

- **Bugs:** tell us what happened, what you expected, and which app version and
  platform you're on.
- **Ideas:** describe the problem you're trying to solve.
- **Please skip code and patches.** We can't accept code contributions, so we
  build every fix ourselves. A clear description helps us most.

## Security issues

Please don't open a public issue. Use **Report a vulnerability** on this
repository's **Security** tab so we can look into it privately.
