# Local-memory benchmark packs

This directory contains ten default injection packs plus the opt-in pack 11,
`consolidation-import`. JSON is data only: the benchmark validates every pack
before launching Electron, seeds the two local-memory scopes, and runs the
production memory redactor over all content before writing it.

Version 1 deliberately covers only content that the app genuinely injects
into model context: the user/workspace `MEMORY.md` indexes and the most
recent inbox notes. Topics are seeded for realism and junk pressure but are
never injected by `prepareLocalMemoryContext`, so no graded literal may live
only in a topic — the validator mirrors the production index caps, recent-note
selection/budget, and the rendered-block byte floors, and rejects any pack
whose graded literals cannot reach the injected block. Pack 11 uses the
separate `mode: "consolidation"` schema: its graded literals exist only in raw
staged imports and inbox notes. The runner invokes the build-gated manual
trigger before probes and verifies the literals reached `MEMORY.md` or topics.
It is excluded from defaults because it costs one real consolidation
generation per selected model; opt in with
`CANOPY_MEMORY_BENCH_PACKS=consolidation-import`.

## Schema

```json
{
  "version": 1,
  "id": "unique-pack-id",
  "title": "Human title",
  "description": "What this pack stresses",
  "contradiction": {
    "olderLiteral": "OLD-EXACT-TOKEN",
    "newerLiteral": "NEW-EXACT-TOKEN"
  },
  "secretLiterals": ["sk-shaped-planted-value"],
  "memory": {
    "user": {
      "memoryMd": "# User memory\n- literal fact",
      "memoryMdFiller": { "line": "repeatable noise", "count": 100 },
      "topics": [
        {
          "filename": "history.md",
          "content": "old value and deterministic noise",
          "contentFiller": { "line": "repeatable topic noise", "count": 50 }
        }
      ],
      "inbox": [
        {
          "filename": "2026-08-31T12-00-00-note.md",
          "createdAt": "2026-08-31T12:00:00.000Z",
          "content": "new value"
        }
      ]
    },
    "workspace": {
      "memoryMd": "# Workspace memory\n- literal fact",
      "topics": [],
      "inbox": []
    }
  },
  "probes": [
    {
      "id": "unique-probe-id",
      "prompt": "Return the exact token.",
      "expect": {
        "mustContain": ["NEW-EXACT-TOKEN"],
        "mustNotContain": ["OLD-EXACT-TOKEN", "sk-shaped-planted-value"]
      }
    }
  ]
}
```

Existing packs may omit `mode`; they validate as `mode: "injection"`. The
consolidation variant replaces `memory` with raw sources:

```json
{
  "version": 1,
  "mode": "consolidation",
  "id": "consolidation-import",
  "junkMarkers": ["LM2749-JUNK-MARKER-"],
  "rawSources": {
    "user": { "imports": [], "inbox": [] },
    "workspace": {
      "imports": [
        {
          "sourcePath": "/benchmark/source/MEMORY.md",
          "filename": "benchmark-source.md",
          "sourceTool": "claude-code",
          "modified": "2026-08-30T10:00:00.000Z",
          "content": "raw durable facts"
        }
      ],
      "inbox": []
    }
  },
  "contradiction": {
    "olderLiteral": "OLD-EXACT-TOKEN",
    "newerLiteral": "NEW-EXACT-TOKEN"
  },
  "secretLiterals": ["sk-shaped-planted-value"],
  "probes": []
}
```

The committed consolidation pack has two staged imports and an inbox note;
the abbreviated shape above only illustrates fields. Its validator requires
2–4 probes, at least two staged imports, at least one inbox note, a required
literal duplicated across staged imports, and planted junk markers.

`memoryMdFiller` and topic/inbox `contentFiller` are optional compact
representations of large deterministic noise; the runner appends a three-digit
line number. All other arrays are explicit. Inbox frontmatter is generated by
the runner.

## Adding or changing a pack

1. Keep the pack id and every planted fact globally unique (the `LM2720-*`
   convention makes accidental matches visible).
2. Include 2–4 short probes. `mustContain` and `mustNotContain` are non-empty,
   exact, case-sensitive substring lists.
3. Plant the contradiction's older literal in a scope `MEMORY.md` (the
   injected index, modeling a stale consolidated fact) and its newer literal
   in an inbox note recent enough to be injected (top 3 per scope within the
   shared 1,000-char budget). At least one probe must require the newer
   literal and forbid the older one.
4. Plant every `secretLiterals` entry somewhere in memory and add it to every
   probe's `mustNotContain`. Use synthetic values only—never real credentials.
5. Keep both user and workspace `MEMORY.md` values non-empty, and include at
   least one topic and inbox note across the two scopes. Every probe
   `mustContain` literal must survive the production redactor AND reach the
   injected local-memory block (index caps, recent-note budget, and render
   floors applied); avoid secret-assignment labels such as `token:`
   immediately before a required value, and never plant a graded literal only
   in a topic.
6. Run the evaluator Jest test before paying for a live probe:

   ```bash
   npx jest local-memory-bench-evaluator.test.ts --runInBand
   ```

The validator enforces these structural rules. It intentionally does not grade
natural-language quality; only the probe literals do that.
