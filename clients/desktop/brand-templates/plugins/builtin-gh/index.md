# Built-In GitHub

GitHub pull request and remote workflow skills bundled with {{BRAND_DISPLAY_NAME}}. These skills cover branch naming, PR creation and maintenance, PR checks/comments, Dependabot triage, PR-aware merge conflict handling, and merging through merge queues.

## Skills

- [branch-naming](skills/branch-naming/SKILL.md) — Branch naming conventions using GitHub identity where available.
- [git-push-pr-sync](skills/git-push-pr-sync/SKILL.md) — Sync PR metadata after pushing.
- [pr-template](skills/pr-template/SKILL.md) — Pull request title and body guidelines.
- [sync-pr-details](skills/sync-pr-details/SKILL.md) — Update existing PR details from current branch changes.
- [handle-dependabot](skills/handle-dependabot/SKILL.md) — Triage and process Dependabot PRs and alerts.
- [handle-merge-conflicts](skills/handle-merge-conflicts/SKILL.md) — Resolve conflicts against a PR/default branch.
- [handle-pr-checks](skills/handle-pr-checks/SKILL.md) — Address failing PR checks.
- [handle-pr-comments](skills/handle-pr-comments/SKILL.md) — Respond to PR review comments.
- [merge-pr](skills/merge-pr/SKILL.md) — Merge a pull request, watch its merge queue, and resolve failures.
- [open-pr](skills/open-pr/SKILL.md) — Create a pull request.
- [push-branch](skills/push-branch/SKILL.md) — Commit, push, and sync PR details.
